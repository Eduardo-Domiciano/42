# src

Código-fonte do frontend Angular.

## Arquivos

| Arquivo | O que faz |
| --- | --- |
| `index.html` | Shell HTML da aplicação. |
| `main.ts` | Bootstrap do Angular. |
| `styles.css` | Estilos globais e fundo da página. |

## Subpastas

| Pasta | O que guarda |
| --- | --- |
| `app/` | Componentes, rotas e serviços. |
| `assets/` | Imagens estáticas (hero). |
| `environments/` | URL da API por ambiente. |
