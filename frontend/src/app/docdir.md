# app

Núcleo da UI Angular.

## Arquivos

| Arquivo | O que faz |
| --- | --- |
| `app.component.ts` | Shell com `router-outlet`. |
| `app.component.html` | Template do shell. |
| `app.component.css` | Estilo do host. |
| `app.component.spec.ts` | Teste do componente raiz. |
| `app.config.ts` | Providers (router, HttpClient). |
| `app.routes.ts` | Rotas da aplicação. |

## Subpastas

| Pasta | O que guarda |
| --- | --- |
| `pages/` | Telas (busca). |
| `services/` | Cliente HTTP da API. |
| `models/` | Tipos TypeScript da API. |
